# DepotIQ Design Document

## System model

One depot supplies many stores. Stores sell products. The depot holds available inventory. The system predicts store-level product demand and recommends shipment quantities from depot to stores.

## Main entities

- User
- Depot
- Store
- Product
- DepotInventory
- StoreInventory
- SalesRecord
- Forecast
- ShipmentRecommendation
- Upload
